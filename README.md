# Mohamed Imthiyaz Portfolio

A responsive, single-page portfolio created from the details in Mohamed Imthiyaz's uploaded resume.

## Run locally
1. Open this folder in VS Code.
2. Open `index.html` directly in a browser, or use the VS Code Live Server extension.
3. No build step or package installation is required.

## Customize
- Replace `assets/profile.jpg` with a higher-resolution profile photo if desired.
- Update project GitHub/demo links in `index.html` when those URLs are available.
